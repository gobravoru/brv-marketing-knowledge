# Playbook — Ingest source

Когда появляется новый источник (интервью с тренером, конкурентский разбор, Exa-find).

## Шаги

1. **Сохрани сырой источник** в `raw/<подкаталог>/YYYY-MM-DD-<slug>.md` без правок. Подкаталоги:
   - `raw/interviews/` — транскрипты звонков с тренерами
   - `raw/competitors/` — разборы конкурентов
   - `raw/sources/` — статьи / посты / Exa-find'ы
   - `raw/product-docs/` — обновлённые продуктовые документы

2. **Прочитай источник целиком.**

3. **Определи затронутые wiki-страницы:**
   - Какие ICP-персоны нужно обновить?
   - Какие concepts затронуты (positioning ⛔, brand-voice ⛔, banned-words ⛔ — только PR; hook-formulas, proof-points — можно обновить напрямую)?
   - Появилась ли новая entity, которой ещё нет?

4. **Обнови wiki-страницы.** Если затронут hard-contract — открой issue в Linear с предложением (не правь напрямую).

5. **Добавь wikilinks** между новым источником и обновлёнными wiki-страницами.

6. **Запиши в `wiki/log.md`:** `YYYY-MM-DD ingest [[source-slug]] → updated [[X]], [[Y]]`.

7. **Обнови `wiki/index.md`** если появились новые разделы или сущности.
