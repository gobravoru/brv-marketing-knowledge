# Campaign 0001 — Warmup content для TG-канала Bravo

Первая контент-кампания. Цель — подготовить ленту канала, прежде чем гнать на него платный трафик из чужих TG-каналов тренеров.

## Контекст

- TG-канал Bravo: ~20 подписчиков (фактически нулевая аудитория).
- Приложение Bravo live в App Store, gobravo.ru работает, триал-флоу готов, подписку купить можно.
- Цели бизнеса: 0 → 1 → 100 платящих за 1-2 мес.
- Эта кампания — **витрина**. Источник трафика — отдельная кампания посева (будет следующей).

## Гипотеза

Если человек придёт в канал по рекламе и увидит 10 постов, в которых:
- узнаёт свою боль,
- видит экспертизу Bravo по тренерскому ремеслу,
- видит продукт через сценарии (а не через лозунги),
- получает понятный мягкий триал-CTA —
он подпишется и зайдёт в триал.

## Структура 10 постов

| # | Тип | Задача |
|---|---|---|
| 1 | Манифест-якорь | Кто мы, для кого. Через интонацию, не через продажу. |
| 2 | Pain-story | Хаос в TG-переписках с клиентами. Формула pain-story из [[hook-formulas]]. |
| 3 | Pain-story | Потеря клиента из-за непрофессионального вида / переноса записи. |
| 4 | Польза без продукта | «Как набрать первых 10 клиентов». Hook на [[young-trainer]]. |
| 5 | Польза без продукта | «Когда блокнот / Excel перестаёт работать». Hook на [[experienced-trainer]]. |
| 6 | Фича через сценарий | Сайт за 15 минут вместо месяцев фриланса. Привязка к gobravo.ru/t/. |
| 7 | Фича через сценарий | Рейтинг и отзывы как социальный капитал. Уникальная фича на ru-рынке. |
| 8 | Proof + soft-CTA | 999/мес, окупается с одного удержанного клиента, 14 дней без карты. |
| 9 | Soft-CTA | «Попробуй, если хочешь увидеть как это работает». Без агрессии. |
| 10 | Story-кейс / FAQ | Реальная история тренера (синтетическая на этой итерации, см. риски) ИЛИ FAQ по триалу. Hype выбирает по результату черновика. |

## Brand voice

См. [[brand-voice]]. Hype пишет от лица Bravo, не от лица Hype. Запреты — [[banned-words]].

## Что писать НЕЛЬЗЯ

- Упоминать WhatsApp как канал общения тренера с клиентом. На ru-рынке у ЦА это Telegram. Используем «переписки в Telegram» / «чат с клиентом» / «текстовые сообщения».
- Слова из [[banned-words]].
- «Покупайте Bravo» в лоб. Это прогрев, а не лендинг.
- Метрики которых нет. См. [[proof-points]] — только то, что подтверждено.

## Метрики кампании

### Воронка

1. **Посев (отдельная кампания, не эта)** → клик в канал
2. **Канал (эта кампания)** → подписка + клик на gobravo.ru
3. **Триал** → installs + trial signups
4. **Платный** → 999/мес

### KPI этой кампании (после первого посева)

| Метрика | Цель | Где смотрим |
|---|---|---|
| Subs канала из посева | +100-200 | TG analytics |
| CTR постов на gobravo.ru | ≥3% best / ≥1% avg | TG link analytics |
| Trial signups из канала | 15-25 | AppMetrica + UTM |
| Paid из канала | 3-5 | App Store + AppMetrica |

«0→1 из этой кампании» = первые 3-5 платных через канал.

### Post-mortem метрики (per-post)

Каждый пост после публикации обмеряем по шаблону `playbooks/post-template.md` и заводим страницу в `wiki/posts/`.

## Риски

- **Нет цитат тренеров** ([[proof-points]] раздел пуст, raw/interviews пусто). Артём выбрал путь Б — пишем сейчас на синтетике из [[raw/product-docs/target-audience]]. После 0→1 заведём интервью и переделаем слабые посты.
- **Нет данных про конкретные TG-каналы посева** ([[entities/competitors]] пуст). Это блокирует следующую кампанию-посев, не эту.
- **Канал на 20 подписчиков** — текущая аудитория не репрезентативна для метрик. Любые KPI меряем только после первого посева, а не сейчас.

## Дальнейшие шаги

1. Кампания → проект в Linear (этот файл = бриф), посты → задачи.
2. Steve зовёт субагента `hype` на каждый из 10 постов по структуре выше.
3. Steve ревью → Артём апрув.
4. Артём публикует руками.
5. Steve заводит per-post страницы в `wiki/posts/` с метриками.
6. После первого посева — анализ KPI, поправка hook-формул, итерация.
