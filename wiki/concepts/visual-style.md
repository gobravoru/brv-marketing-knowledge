# Visual style — визуальный канон обложек Bravo 🔒

> **🔒 Hard contract.** Визуальный язык обложек — аналог [[brand-voice]] для картинок. Меняется только с явного согласия Артёма. v2.0: собран по атласу референсов (159) и реальным выборам; модель «замок + оси». История решений — [[learnings]] и `log.md`.

## Процесс

- **Генератор:** OpenAI gpt-image-2, text-to-image (канон самодостаточен текстом), quality=medium. Реальный скрин продукта — единственный случай image-to-image (`/images/edits`); выдуманные UI не рисуем.
- **Промпты:** skill `generate-cover-prompts` — hype отдаёт 3 промпта = 3 разные комбинации осей.
- **Слоган** — заголовок, выбранный при ревью поста (`headline-craft`), в промпт дословно в кавычках.
- **Доставка:** `tg-pipeline/cover.py` → R2 → комментарий в Linear → выбор Артёма → реестр.

## 1. Принцип: замок + оси

Каждый кадр — рекламный editorial спортивного бренда уровня Nike / On / lululemon. Проверка: **сильно · чисто · атмосферно**.

- **Замок** (константы — в каждом кадре): premium sport-editorial эстетика; живая фотография (плёночный язык, не пластик); славянская внешность, сухой атлетичный типаж 20–40, НЕ качок; спорт/движение/профессия тренера; чистый фон, воздух под текст; слоган дословно; **маленькая лайм-деталь `#D0FF00`** (кант, шнурки, плашка, линия) — доза варьируется, полное отсутствие — редкое осознанное исключение.
- **Оси** (раздел 3) обязаны меняться между кандидатами и постами. Однотипность = одинаковые свет/грейд/эмоция/тип-слой при разных сценах.

Настроение атласа: палитры полихромные (лайм — гость, не хозяин); много жёсткого света (вспышка, контровой, сумерки), не только high-key; фокус-лица и улыбки примерно поровну; типографика смелая. **Дизайн-паттерны** (в арсенале, не обязательны): ленты/росчерки поверх фото · стикеры/бейджи · halftone · wireframe-разметка · цветные блок-фигуры · коллаж · гигантский вордмарк · fisheye.

**Выборы Артёма в Linear** — относительный сигнал («лучшие из вышедшего», планка — атлас). Побеждали: урбан/золотой час чаще всего; также соло на заливке, йога-минимал, тренер+клиент. По его предметному фидбэку заходят: low-key типографика-постер с контрастом масштабов, flash-минимал, wireframe-стрелки + лайм-плашка.

## 3. Оси вариаций

3 кандидата = 3 разные комбинации (fan-out, не парафразы). Перед сборкой — оси последних 5 обложек ленты: не повторять комбинации, не давать 2 подряд одинаковых грейда/тип-приёма.

| Ось | Значения |
|---|---|
| Дисциплина | бег/трек · теннис · йога/пилатес · функционалка · бокс · силовая · плавание · вело · скейт · танец/гимнастика · баскетбол · трейл · калистеника/паркур · athleisure |
| Состав | соло · тренер+клиент · тренер+группа (2–4) · дуэт |
| Пол | муж · жен (чередовать) |
| Тип кадра | средовой · фигура на бесшовке · цветной блок · кроп-деталь · продукт/инвентарь · со спины · силуэт · коллаж · лицо крупно · чисто типографический |
| Ракурс | низкий геройский · уровень глаз · top-down · dutch · профиль в движении · экстрим-кроп · из-за плеча · fisheye · worm's eye · общий план с маленькой фигурой |
| Грейд | один из 6 пресетов (раздел 4) |
| Среда | заливка любого цвета · урбан/крыши · трек · корт · бассейн · природа · побережье · улица · зал moody · минимал-студия · небо |
| Эмоция | сфокусирован/невозмутим · candid-момент · спокойствие · искренняя улыбка · азарт/триумф — микс; улыбка не дефолт |
| Типографика | раздел 5, приём обязан меняться |
| Дизайн-паттерн | 0–1 из списка раздела 2 |
| Доза лайма | слово · плашка · деталь одежды/сцены · подчёркивание; цвет текста — белый/чёрный/цветной |

Ориентир по тону поста: драйв → экшн, низкий ракурс, урбан/трек; продукт/боль-рутины → тренер+клиент, из-за плеча, фокус; mind-body → йога, мягкий свет, спокойствие; комьюнити → пары/группа, candid; результат/цифры → портрет/кроп + гигантское число.

## 4. Грейд-пресеты (по одному на кандидата)

1. **BRIGHT HIGH-KEY** — `bright airy high-key daylight, directional light with soft shadows, clean light interior, fresh uplifting energy`
2. **GOLDEN URBAN** — `golden hour backlight, warm rim light on the silhouette, urban concrete environment, long shadows, sun flare`
3. **COLOR-BLOCK STUDIO** — `seamless bold colored backdrop, sculpting softbox light, fashion campaign look` (цвет любой: горчица, синий, розовый, терракота, красный…)
4. **EARTHY CALM** — `warm earthy palette, soft window light, long calm shadows, matte premium look`
5. **FLASH EDITORIAL** — `direct camera flash, hard shadows, spontaneous editorial energy, slight vignette`
6. **LOW-KEY DRAMATIC** — `hard directional key light, deep shadows, high contrast, dark background, visible sweat`

Один кадр — одна цветовая доминанта.

## 5. Типографика

Слоган всегда, дословно, читаемый. Приём меняется от поста к посту: гигантский гротеск капсом · текст за фигурой · контур · вертикаль/диагональ · гигантское слово/число · masthead+cover-lines · минимал с воздухом · лайм-плашка · цветной текст · контраст масштабов · сериф/курсив-акцент на одном слове.

- **Two-tier:** короткая главная строка + опциональный кикер; длинный заголовок — на ярусы.
- **Только прямые строки и диагонали.** Дуги/кольца/обтекание ломают кириллицу — брак. Также брак: граффити-шрифт, сериф как основной.
- **Читаемость лайма** на светлом: плашка с тёмными буквами / обводка / тёмный участок.
- **Safe-зоны:** верх/низ ~10% кадра без текста.
- Тон — `headline-craft` + [[headline-swipe]]: живая фраза, без рекламных приказов.

## 6. Сцена, кастинг, физика

- Сцену писать конкретно (одежда, фактуры, пропсы), не «спортсмен в зале» — конкретика вытесняет стоковый дефолт.
- В каждый промпт: `Eastern European / Slavic appearance, white European model`. Лица живые, фактура кожи, пот — плюс. Позы: движение/асимметрия/candid.
- **Простая физика:** без сложного реквизита в контакте с телом (барьер в прыжке, ракетка в замахе, партнёр в динамике за спиной) — зона артефактов; один герой-объект, контакт однозначный.
- **Без кино-постановки:** сторителлинг только candid-натуральный, не «кадр из фильма» с костюмами и мизансценой.

## 7. Промпт-гигиена gpt-image-2

1. Порядок: `intended use → сцена+субъект → действие/эмоция → среда → грейд-пресет → палитра → layout/зоны → типографика + "СЛОГАН" → констрейнты текста`.
2. ≤ ~200 токенов; один стиль-якорь + 1–2 поддержки, без стопки прилагательных.
3. Не писать `photorealistic` (пластиковые лица) — вместо: `35mm film photograph, natural grain, shallow depth of field`.
4. Негативы — позитивно («no flat lighting» → `directional light with character`). Исключение — текст: `render the headline verbatim, no other text anywhere`.
5. Слоган в кавычках, КАПСОМ, типографика инлайн (шрифт, цвет, позиция). Воздух под текст указывать явно.
6. Итерация: кандидат «почти» → менять ровно одну переменную; промпт верен, бросок кривой → перебросить тот же промпт; сломана буква → переброс + `letter by letter Х-В-А-Т-И-Т`.

## 9. Стоп-лист

Темнокожие/неевропейские модели · гримасы боли и фальшивый сток-позитив · качки, пластиковая кожа · «руки скрещены», фронтальный сток · телефон в камеру · выдуманные UI · распродажный баннер · толпа, мусорный фон · паразитный текст помимо слогана · кривая кириллица, артефакты анатомии · заливка всего кадра лаймом · мультяшность/3D-рендер.

## 10. Чеклист кандидатов

1. Тройка различается минимум по 3 осям; комбинации не повторяют последние 5 обложек ленты.
2. Слоган дословный, кириллица чистая, физика сцены не сломана (реквизит, руки, партнёры).
3. Эмоции в тройке разные; лайм-деталь на месте.
4. Есть ≥1 смелый кандидат уровня атласа.
