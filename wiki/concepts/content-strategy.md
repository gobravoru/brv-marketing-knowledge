# Content strategy — канал bravo_pro

Как планируем контент, чтобы кампании не повторялись и работали на стратегию. Канал = audience-building (см. [[telegram]]): ценность + дозированное промо (~80/20).

## Источники тем (главный антидот к повторам)

Темы НЕ выдумываем из головы — берём из реальности:
1. **Customer dev** (outreach `BMK-10`, [[learnings]]) — боли, возражения, фразы, вопросы тренеров. Главный источник: уникально и автоматически вписано в стратегию.
2. Вопросы / возражения клиентов, отзывы, ошибки.
3. Конкуренты ([[competitors]]), рынок, сезон.

→ Каждый инсайт из customer dev = кандидат в пост. Пока копаем активацию — поток свежих тем не иссякает.

## Рубрики (pillars)

Постоянный каркас. Каждая кампания = свежий **микс** рубрик, а не набор тем с нуля.

**Тематические:**
- Боль операционки (хаос записей, переписки, переносы)
- Деньги и рост (цены, потолок, масштаб без выгорания)
- Привлечение и упаковка (первые клиенты, сайт, отзывы, позиционирование)
- Удержание и работа с клиентом (конверсия, возвраты, психология)

**Фича-рубрики** (по ключевым функциям — каждая раскрывается серией, см. ниже):
- Онлайн-запись 24/7
- Персональный сайт тренера
- Авто-сбор отзывов / рейтинг
- Напоминания клиентам
- CRM / клиентская база
- *(дополняется по мере фич)*

## Фича-серии (раскрытие фичи без «продуктовой брошюры»)

Каждую фичу раскрываем серией ~3–4 постов, **разнесённых во времени и перемешанных** с другими рубриками (не подряд!). Цепочка (best practice: problem → alternatives → solution):

1. **Боль / ценность** — без продукта, через жизнь тренера. Узнавание. Hook: pain-story / hard truth.
2. **Решение без нас** — без продукта: как тренеры справляются сейчас, ручные способы, лайфхаки. Честно и полезно — экспертиза + естественный потолок ручного подхода.
3. **Решение с нами** — софт-промо: тот же сценарий через фичу Bravo, как стало проще. Hook: compare-then-flip / сценарий. Мягкий CTA (демо-профиль → лендинг, см. [[demo-profiles]]).
4. *(опц.)* **Доказательство** — демо-профиль / отзыв / мини-история.

### Ограничители — чтобы не перегибать
- Между постами одной серии — **2–4 поста из других рубрик**. Серия «тлеет», не давит.
- Только **1 из 3 постов серии — с продуктом**. Держим общий ~80/20 по каналу.
- «Решение без нас» — **искренне полезное, не соломенное чучело**. Доверие важнее манипуляции.
- **Одна активная фича-линия за раз** — не гнать несколько фича-серий плотно параллельно.

## Антиповтор

- Перед кампанией сверяюсь с реестром использованных тем/углов ([[learnings]] + `posts/`) — не повторять угол.
- Что зашло по метрикам → усиливаем новым углом; что не зашло → убираем.
