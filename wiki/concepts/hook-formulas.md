# Hook formulas

Формулы цепляющих первых строк для постов. Дополняется опытом.

## Pain-story

> «Тренер N потерял Y клиентов из-за Z. Знакомо?»

Когда работает: когда есть конкретный случай / цитата из интервью (`raw/interviews/`).

## Hard truth

> «Если ты ведёшь клиентов в Telegram — ты теряешь Y%».

Когда работает: когда есть метрика. Без метрики выглядит как буллшит.

## Compare-then-flip

> «Раньше X. Теперь Y».

Когда работает: для тренеров, которые что-то поменяли в практике.

## Question lead

> «Сколько клиентов ты потерял из-за переноса записи?»

Когда работает: когда ответ для читателя — болезненная цифра.
