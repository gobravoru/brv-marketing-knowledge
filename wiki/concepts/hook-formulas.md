# Hook formulas

Формулы цепляющих первых строк для постов. Дополняется опытом.

## Pain-story

> «Тренер N потерял Y клиентов из-за Z. Знакомо?»

Когда работает: когда есть конкретный случай / цитата из `raw/interviews/`.

## Hard truth

> «Если ты ведёшь клиентов в Telegram — ты теряешь Y%».

Когда работает: когда есть метрика. Без метрики выглядит как буллшит.

## Compare-then-flip

> «Раньше X. Теперь Y».

Когда работает: для тренеров, которые что-то поменяли в практике.

## Question lead

> «Сколько клиентов ты потерял из-за переноса записи?»

Когда работает: когда ответ для читателя — болезненная цифра.

## Scene-lead

> «Девять вечера. Телефон не замолкает: „когда удобно?“, „сколько стоит?“ — отвечаешь в третий раз за день.»

Когда работает: почти всегда для hook-постов. Открытие конкретной **сценой**, где тренер узнаёт себя сам (show, don't tell), вместо ярлыка-утверждения о нём («ты любишь…»). Дефолт по anti-AI правилам [[write-telegram-post]]; нужен якорь конкретики (время, реплики, число). Разнообразит ленту, когда соседние посты идут на compare-then-flip.
