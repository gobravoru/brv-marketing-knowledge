# Конкуренты — обзор (ru-рынок)

Точных долей рынка нет — карта по позиционированию.

## Прямые (частный тренер + сайт/CRM)

- **TRENERA.PRO** (trenera.ru) — ближайший аналог Bravo: мини-сайт тренера, CRM, расписание, программы тренировок, отзывы, чат с клиентом; федеральная платформа «найди тренера». **Главный конкурент по позиционированию.**
- **7Coach** (7coach.pro) — CRM для тренера: учёт клиентов, расписание, контроль оплат/абонементов, доходы. Premium-подписка, 7 дней триал. Без акцента на персональный сайт.

## Широкие (запись/CRM для услуг, не только тренер)

- **EasyWeek, Reservio** — онлайн-запись + сайт записи, напоминания; ниша всех услуг.
- **YCLIENTS, DIKIDI** — лидеры онлайн-записи РФ, заточены под бьюти/салоны; есть готовый трафик (маркетплейс мастеров).
- **Планёрка, Rient, Rubitime, Bumpix** — лёгкая запись для самозанятых/мастеров.

## Для клубов/студий (не наш сегмент)

- **Mobifitness, FitBase, impulseCRM, Параплан, 1C:Фитнес** — управление клубом/студией, мультисотрудники.

## Вывод для позиционирования

Ниша «**частный тренер + собственный сайт + отзывы как соцкапитал**» почти пустая — прямой сильный игрок один (TRENERA.PRO). Это окно для [[positioning]] Bravo. Отличие Bravo — упор на персональный сайт-витрину (gobravo.ru/t/) + рейтинг, а не только внутренняя CRM. Требуется детальный разбор TRENERA.PRO (отдельная задача).

## Источники

- vc.ru «топ-11 онлайн-записи» (2025-11), picktech каталог ПО для тренера, лендинги 7coach.pro, trenera.ru/app-pro, easyweek.ru, reservio.com (разбор 2026-05-25).
