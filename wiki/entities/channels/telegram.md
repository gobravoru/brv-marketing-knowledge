# Telegram

Стартовый канал Bravo. По данным из [target-audience](../../../raw/product-docs/target-audience.md) — основная ставка для общения с тренерами.

## Текущее состояние (на 2026-05-25)

Канал [@bravo_pro](https://t.me/bravo_pro) ведётся Артёмом. На 2026-05-25:
- **~37 постов** опубликовано, лента живая и качественная: мотивация + практика для тренеров + органичные промо BRAVO со ссылками на gobravo.ru.
- **21 подписчик.** Просмотры постов 20–50 (растут к свежим: последние посты 40–51). Местами просмотров больше подписчиков (51 при 21) → есть внешний приток/пересылки.
- **CTA в ленте мягкие** — ведут на gobravo.ru, ни одного явного «поставь приложение / начни бесплатно».

Вывод: **витрина готова, контент-движок работает.** Бутылочное горло НЕ в контенте, а в трафике (аудитории ~0) и ещё раньше — в trial→paid (см. [[learnings]]). Поэтому канал переведён в режим «поддержание регулярности» (проект Linear «Контент · Telegram»), а не «строить витрину с нуля». Старый план [[0001-warmup-content]] на этом основании устарел.

Источник 21 подписчика: разовая РК в **Telegram Ads** (~5 000 ₽ → 21 подписчик ≈ 240 ₽/подписчик; конверсия канал→trial→paid не доказана — см. [[learnings]]).

## Почему

- Тренеры активно сидят в Telegram (профессиональные чаты, каналы)
- Реклама дешевле Instagram
- Возможность строить личный канал бренда с органикой

## Форматы

- Hook-посты 800-1200 знаков
- Story-посты 1500-2500 знаков
- FAQ/инструкции 1000-2000 знаков
- Обложка — по сигналу Артёма после выбора заголовка (заголовок-gate, см. brief-content-task); генерит конвейер обложек (cover.py) по канону [[visual-style]]

## Боевой канал

**[@bravo_pro](https://t.me/bravo_pro)** (id `-1002279724681`) — тот же канал, что Артём вёл сам (~37 органических постов). С 2026-07 — рабочий канал производства: сюда публикует конвейер. Бот-постер `@steve_brv_bot` — админ с правом Post messages. Задаётся env `TG_CHANNEL=@bravo_pro` (в `poster.py` и в облачной рутине).

## Доставка и аналитика — гибридная архитектура

Решение 2026-07: **бот публикует, MTProto читает**.
- **Публикация** — бот через `poster.py` из реестра (Bot API; просмотры постов ботам недоступны в принципе).
- **Метрики постов** — `tg-pipeline/post_metrics.py` (read-only MTProto user-session, аккаунт-сборщик): views/forwards/reactions по постам канала, наши тегаются по `message_id` из реестра (органические тоже пишутся — базовый срез), история в листе `post_metrics` Sheet, upsert по (date, message_id). Построен и протестирован локально 06.07 (база 26 постов захвачена). Полная stats.* откроется при ~500 подписчиков теми же ключами. `BMK-140`; факты — [2026-07-03-telegram-bot-vs-mtproto-research](../../../raw/sources/2026-07-03-telegram-bot-vs-mtproto-research.md). Облачный запуск ждёт настройки сети рутины под MTProto (Telegram DC — IP-диапазоны, не `api.telegram.org`).

## Метрики, которые отслеживаем

Канал мерим **здоровьем сообщества**, не атрибуцией в платящих: роль — верх/середина воронки (community), связь с NSM непрямая через доверие и referral ([[content-strategy]] «Роль канала»). Снимает `post_metrics.py`.

- рост подписчиков
- views — охват (MTProto-сборщик, BMK-140)
- **forwards — главный сигнал ценности** (vs views = коэффициент вирусности)
- reactions
- link-clicks на gobravo.ru — вторичный сигнал интереса; прямой trial→paid ведут SEO/таргет, не канал

## Что зашло / не зашло

Первичный срез по просмотрам (на 2026-05-25, без TG-аналитики — только public-preview, грубо): больше всего просмотров собрали посты про **«меньше работать — больше зарабатывать»** (51), **отзывы как соцдоказательство** (42), **чек-лист первой тренировки** (41), **позиционирование** (39). Меньше — короткие мотивационные/философские. Гипотеза: практика + деньги тренера заходят лучше абстрактной мотивации. Не подтверждено реакциями/конверсией — уточнить, когда будет TG-аналитика. См. [[learnings]].
