# Атлас референсов Bravo — пер-кадровый разбор (159 кадров)

Методика: Steve разбирает каждый кадр атласа (`~/Downloads/bravo_референсы_фото/ATLAS/`) своими глазами, батчами по ~10, по единой рубрике (ниже). Категории-папки — только маршрут обхода; таксономия визуальных подходов строится bottom-up из карточек (спорт — атрибут, не категория). Частоты дескриптивны, НЕ квоты ленты (выборка = «что нравится Артёму», не целевые пропорции). Дизайн: `docs/superpowers/specs/2026-07-02-visual-atlas-system-design.md`.

## Рубрика оценок

Шкала «эталонность для ленты Bravo» (не «красиво вообще», а «хотим ли мы так»):

- **5 — образец.** Кадр делает минимум две вещи сразу: живой момент/концепт + графическая режиссура; приём переносим в Bravo немедленно. Якоря: `02_tennis/0c9a8e4a…` (top-down candid «между», акцент в микродеталях), `06_portrait_colorblock/05db4d05…` (имя тренера как бренд + ленты).
- **4 — сильный приём.** Одна отчётливая идея, чисто исполнена, но без второго слоя (сюжета/бренда). Якорь: `03_yoga_dance/0a7ed6aa…` (симметрия + total-look; берём приём, не ракурс).
- **3 — стильно, но generic.** Хороший грейд/кастинг, но ни идеи, ни режиссуры — «любой бренд». Якорь: заполнить первым же кадром этого уровня в батчах.
- **2 — сток с хорошим светом.** Постановочность видна, приёма нет. Якорь: по ходу.
- **1 — сток.** Каталог фитнес-клуба. Якорь: по ходу (в атласе может не оказаться — Артём отбирал вкусом).

_Правило сверки: перед каждым батчем перечитай якоря; если сомневаешься между двумя оценками — сравни с якорем, а не с соседним кадром батча._
