# Content-ops best practices — ресёрч (Exa, 2026-06-17)

Ресёрч под Блок 2 (инкубатор кампаний + планировщик публикаций). Источник синтеза для [[content-strategy]] и дизайна планировщика.

## Ключевое

1. **Stages, not dates** (решает нашу боль протухших дат). Не назначать дату публикации при планировании кампании. Дату пост получает, **когда готов** (прошёл review) — из очереди по ритму. «Stop assigning publish dates until ready.» «Schedule capacity, not topics.»
2. **WIP-лимиты по стадиям, идеи не жмут внимание.** Кап «в работе» ~6 штук (attention — узкое место, не throughput). Идеи в backlog (Idea) НЕ считаются в кап. → «10 кампаний/10 постов» = backlog идей, а активная работа лимитируется.
3. **Priority scoring очереди.** «Что публиковать следующим» = скоринг (impact/effort/цель). Недельный 10-мин backlog review. Топ → в ближайшие слоты.
4. **Три горизонта.** Стратегия 90 дн (темы) → тактика 30 дн (конкретные посты) → операционка 7–14 дн (locked, готово). Ближний горизонт не трогаем без крайней нужды.
5. **Buffer.** Публикуешь 5/нед — планируй 4 заранее, 1 слот буфер (timely/follow-up/проскальзывание).
6. **Kill rule.** Backlog — не кладбище. Новую идею в полный кап — только вытеснив другую. «Kill, don't park.»
7. **Sequencing.** Связанные посты (фича-серия) — по порядку, разнесены во времени. У нас уже есть (боль→без нас→с нами).

## Частота (наши 5/нед — в норме TG)

- Блог/SEO early-stage: 2–4/мес, консистентность > объём.
- **Telegram: 1–3/день sweet spot; кейсы 5–6/нед** (Bellumera $10K MRR — 5–6/нед фиксированной сеткой по дням). Предсказуемость = привычка = retention.
- 5/нед для нас — здоровая TG-частота, даже консервативная.

## TG-специфика

- Промо ≤ 20–30% (4:1 value:promo). Наш ~80/20 — верно. 80%+ промо → −30–40% подписчиков/мес.
- Длина 100–400 слов (scannable). Пики: 7–9 / 12–14 / 19–21 МСК.
- View rate 50%+ healthy, reactions 5%+. Канал = **conversion surface** (двигать к trial), не feed («новая статья вышла» = смерть).
- НЕ link-dump, НЕ AI-slop (TG-аудитория детектит), НЕ промо-перегруз.
